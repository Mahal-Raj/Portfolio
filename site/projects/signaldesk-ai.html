01 / OVERVIEW

Built around a real operational decision.

SignalDesk converts an unstructured operational alert into a category, severity, responder team, runbook and similar historical cases without sending incident text to an external model.

Incident queues mix noisy language, sensitive details and repeated failure patterns. The project creates a transparent first-pass triage workflow while keeping a human responsible for every operational action.

  • TaskSix-class incident routing
  • Evaluation81.7% accuracy and macro-F1
  • PrivacyRedaction before inference
  • ModelTF-IDF + logistic regression

04 / WORKING DEMO

Watch an alert become an explainable response path.

The working demo redacts sensitive values, classifies an incident locally, exposes the weighted evidence, and returns the relevant responder, runbook and similar resolved cases.

05 / HONEST SCOPE

Implemented claims stay separate from future infrastructure.

The bundled corpus is deliberately small and demonstrates the complete ML lifecycle. Low-confidence or unfamiliar incidents require human review before any operational decision.
