03 / AN OPERATING METHOD

Stay calm.
Make the system smaller.

When something breaks, I want the next action to reduce uncertainty rather than add noise.

  1. 01

    Observe

    Start from the behaviour I can verify.

  2. 02

    Isolate

    Reduce the system to the smallest uncertain boundary.

  3. 03

    Explain

    Make the problem and the next step understandable.

  4. 04

    Improve

    Document the lesson or automate the repeatable part.
